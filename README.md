# LearnYos

**LearnYos** is a study platform for creating exams and flashcards to practice for any important test — from school assessments to Colombia's ICFES exam. It includes **Junior AI**, a virtual-teacher chat that answers questions and explains topics as you study.

🔗 **Live demo:** [learnyos.vercel.app](https://learnyos.vercel.app)

---

## ✨ Features

- **Exam generation** — practice exams with context and reasoning, not just plain question lists.
- **Flashcards** — structured for efficient memorization and review.
- **Junior AI** — an AI chat that acts as a virtual tutor, answering doubts and explaining topics.
- **My Space** — manage your own exams and flashcards, review notes, and organize your study process.
- **Public/private content** — choose what you share with others and what stays personal.

## 🛠️ Tech Stack

| Layer | Technology |
|---|---|
| Frontend | Next.js, React, TypeScript |
| Backend | NestJS |
| Database | PostgreSQL |
| AI | Gemini |
| Auth | OAuth |
| Deployment | Vercel (frontend), Render (backend) |

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/xenoxf/learnyos-x2.git
cd learnyos-x2

# Install dependencies
npm install

# Run the development server
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000) in your browser.

> Note: some features (like Junior AI) may require environment variables/API keys to be configured. Check for a `.env.example` file or ask the maintainer for setup details.

# LearnYos (Español)

**LearnYos** es una plataforma de estudio para crear exámenes y flashcards y practicar para cualquier evaluación importante, desde exámenes escolares hasta el ICFES. Incluye **Junior AI**, un chat que funciona como profesor virtual, respondiendo dudas y explicando temas mientras estudias.

🔗 **Demo en vivo:** [learnyos.vercel.app](https://learnyos.vercel.app)

## ✨ Funcionalidades

- **Generación de exámenes** — exámenes de práctica con contexto y razonamiento, no solo preguntas simples.
- **Flashcards** — estructuradas para memorizar y repasar de forma eficiente.
- **Junior AI** — un chat de IA que funciona como profesor virtual, resolviendo dudas y explicando temas.
- **Mi Espacio** — administra tus propios exámenes y flashcards, revisa notas y organiza tu proceso de estudio.
- **Contenido público/privado** — decide qué compartir y qué mantener personal.
